Help

What each part of the site is for.

Resources

Browse what other people shared. Pick a category on the left, then download a file or copy a script. Top resources lists the most downloaded ones.

Share

Upload your own script (.lua, .txt) or model (.rbxm, .rbxl, .rbxmx). Add a title, a category and a short description so others know what it does. You need to be signed in to claude.ai to share.

API

Lets you read the site's data as JSON: the list of resources, one resource by id, or the raw text of a script. Use it to check what the data looks like or to export everything. The API page works inside this site only.

Announcements

Official news about the site: new features, events and important notices.

Changelog

The history of updates, listed by version, so you can see what changed and when.

Join Discord

The button in the top bar opens our Discord server for questions, feedback and support.
